# Monmish Book——梦谜语的语法、语汇和语料库

## 1 何为梦谜语？

> 创世之初，人类与宝可梦共用一种语言。  
> 后来它分成了两种：一种太简单，说不清；一种太复杂，不敢说。  
> 于是，一只躲在布偶里的谜拟丘，创造了第三种。  
> 它很简单，很规律，也很精确——  
> 简单到任何宝可梦都能学会，精确到能说出「我害怕」。  
> 这就是「**梦谜语**」。

梦谜语是基于宝可梦世界观创造的人造语言，设定为谜拟丘创造的语言，最终成为宝可梦与人类共同语言
