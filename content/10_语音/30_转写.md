梦谜语的拉丁转写、西里尔转写分别基于波兰语、俄语设计

## 1 音素对应

### 1.1 元音对应

| 音素  | 拉丁转写 | 西里尔转写 |
| :-: | :--: | :---: |
| /ɑ/ |  a   |   а   |
| /ɛ/ |  e   |   е   |
| /ə/ |  ę   |   э   |
| /i/ |  i   |   и   |
| /ɔ/ |  o   |   о   |
| /ɯ/ |  ó   |   ю   |
| /u/ |  u   |   у   |
| /ʏ/ |  y   |   ы   |

### 1.2 辅音对应

|    音素     | 拉丁转写 | 西里尔转写 |
| :-------: | :--: | :---: |
| /b/ ~ /p/ |  b   |   б   |
|   /pʰ/    |  p   |   п   |
| /d/ ~ /t/ |  d   |   д   |
|   /tʰ/    |  t   |   т   |
| /g/ ~ /k/ |  g   |   г   |
|   /kʰ/    |  k   |   к   |
|    /m/    |  m   |   м   |
|    /n/    |  n   |   н   |
|    /ɲ/    |  ń   |   я   |
|    /v/    |  w   |   в   |
|    /f/    |  f   |   ф   |
|    /z/    |  z   |   з   |
|    /ʑ/    |  ź   |   ё   |
|    /ʒ/    |  ż   |   ж   |
|    /s/    |  s   |   с   |
|    /ɕ/    |  ś   |   щ   |
|    /ʃ/    |  sz  |   ш   |
|  /t͡sʰ/   |  c   |   ц   |
|  /t͡ɕʰ/   |  ć   |   ч   |
|    /x/    |  h   |   х   |
|    /j/    |  j   |   й   |
|    /w/    |  ł   |  ль   |
|    /ɫ/    |  l   |   л   |
|    /ɾ/    |  r   |   р   |
